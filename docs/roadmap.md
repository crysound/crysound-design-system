# 后续产品化路线

0.2.0 已实现：33 类组件、逐组件中文文档、代码/API 标签页、双主题双密度、客户换肤、软件/官网表面、DataTable、测量任务配置、源码 Registry 及验证脚本。

已取得三个 Figma 画布结构、代表节点截图与上下文，以及软件/官网变量。品牌与灰阶有来源，深色主题与新增组件细节仍需扩大逐状态核对。

下一阶段：日期与时间选择、树结构、命令面板、复杂菜单、虚拟滚动、服务端表格、拖拽布局。按实际产品需求优先级推进，避免用外观占位冒充行为。

仪器业务阶段：设备连接向导、校准流程、真实测量任务与报告摘要。频谱、波形、声学热力图需要真实数据契约、单位、缩放、时间与无效值规则。

工程成熟阶段：独立 Storybook、视觉回归、完整无障碍审查、Changesets、受控包发布、私有 Registry 托管与 Figma Code Connect。当前 npm 包未发布。
