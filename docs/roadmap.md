# 后续产品化路线

首版已实现：双主题、双密度、客户主题示例、8 类组件、中文交互文档、ESM/类型构建、交互测试与 CI。

已取得：三个 Figma 画布结构、代表节点截图与上下文，以及软件/官网变量。下一阶段：扩大组件逐状态核对，补齐完整 Token 映射与视觉回归。

产品组件阶段：按真实业务优先级添加 Select、Checkbox、Switch、Tabs、Tooltip、Toast、分页/排序/选择表格。每个组件先确定交互契约再实现，避免仅有静态外观。

仪器业务阶段：参数表单、设备连接向导、校准流程、测量任务、报告摘要。频谱、波形、声学热力图必须有真实数据契约、单位、缩放与无效值规则。

工程成熟阶段：组件独立 Storybook、自动视觉回归、完整无障碍审查、Changesets、受控包发布、可选 shadcn registry、Figma Code Connect。以上未在首版实现。
