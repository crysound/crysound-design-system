# 预览站布局参考

本次仅调整文档与预览站，保留 CRYSOUND 品牌 Token、33 类组件和既有 API。

来源：[Untitled UI 组件总览](https://www.untitledui.com/react/components) 与 [按钮详情](https://www.untitledui.com/react/components/buttons)。已检查 1280 × 720 桌面和 390 × 844 手机布局。

## 已采用的结构

- 桌面：248px 固定侧栏、56px 固定顶部栏、32px 内容内边距。
- 标题：24px / 32px、600 字重；说明正文 16px / 24px；Inter 自托管字体，中文使用系统回退。
- 总览：基础 / 应用 / 仪器组件分组，桌面四列预览卡片，手机单列。每张卡片用真实 CRYSOUND 组件或原生展示元素生成缩略预览。
- 详情：标题与相邻导航、资源链接、示例工具栏、Preview/Code 切换、20px 圆角且至少 320px 高的预览框、安装说明、状态变体和 API。
- 手机：64px 顶部栏、16px 内容边距、抽屉式导航；工具栏分两行，预览/代码切换置前，按钮主示例竖向排列。
- 搜索：侧栏搜索按钮与 `/` 快捷键打开搜索对话框；手机菜单内提供组件搜索。

## 保留的差异

主色、组件圆角、状态色和业务内容属于 CRYSOUND。未复制 Untitled UI 标识、商业缩略图片或付费组件资源。文案长度、组件数量和仪器分类会造成自然的内容高度差异，不宣称整站逐像素复刻。

字体与图标通过开源 npm 包引入，其许可文件保存在文档站 `public/licenses`。导航、主题设置、移动端菜单与现有组件仍保持可交互。
