# 场景样板首轮

本轮为用户确认的三个场景制作独立可操作样板，入口 `#scene-styles`。新增页面与局部样式，不替换既有页面或共享组件默认值。所有场景尺寸是工程建议，尚不是已验证的生产预设。

| 场景 | 主角与结构 | 角色和密度 |
| --- | --- | --- |
| 精密工作台 | 设备选择、配置面板、信号监视，操作紧邻参数 | 页面24/32、正文14/22、辅助12/18、桌面控件32px |
| 理性数据 | 摘要→趋势→明细→待复核信息，共用一个页面表面 | 主指标30/40、正文14/22、辅助12/18、区块24px |
| 品牌展示 | 产品图与标题主导，产品分类、系列说明和官网入口 | 首屏36/44、区域30/40、产品20/28、正文16/26 |

复用 Tabs、Button、Input、Select、StatusBadge、LineChart、Progress、Dialog。桌面工作台有侧导航；容器较窄时先取消内侧导航，≤640px内容单列。手机交互目标保持至少44px，设备行≥64px，分析表格在局部区域滚动。

## 交互与数据边界

设备选择与搜索、开始/停止、参数锁定、分析指标与周期切换、CSV导出、产品分类与系列弹窗均为本地交互。开始测量不会发送硬件请求；导出仅包含当前合成图表数据。外部官网链接保持用户主动点击。样板范围说明放在画面外，不将演示成功冒充服务端成功。

共享Tabs指示器、控件按压反馈和Dialog进出动画沿用组件库；设备行仅改变背景，产品图片在精确指针悬停时轻微缩放。减少动态效果时取消过渡和滚动动画。

### 独立样板预览

提供 `#scene/precision`、`#scene/analytics`、`#scene/brand` 三个独立路由，顶部可切换场景或返回规范。独立预览移除文档侧栏，便于按实际产品页面的宽度评估。

本轮深化：数据页使用直接的任务标题，突出摘要、趋势和复核原因；品牌页改为居中产品展示，测量链路与探索入口位于两侧。工作台维持浅色任务画布，避免大面积深灰背景。三种布局均保留共享组件的键盘、主题和本地交互行为。

工作台配色收敛（提案）：背景、边界和文字采用同一中性灰色系；导航与设备选中态用浅灰承托。品牌色用于主操作和选中勾选；信号波形使用中性深灰，避免与操作色竞争。绿、橙仅表达状态。深色模式同步采用中性灰层级，客户品牌色继续继承根配置。此提案仅作用于工作台样板，不修改全局令牌。

品牌展示更新为本地“官网-全新改版”的视觉表达：白色导航、左文右图产品横幅、各产品对应的浅灰冷暖底色、胶囊主操作及底部手动产品切换。沿用本地官网的 hero-monitor、hero-rack、hero-slide-sonocam-pi、hero-slide-pocket 四张用户项目素材，复制到 scene-assets 独立目录；不修改官网源项目。样板文案为简化中文展示，不扩展或承诺性能参数，不包含自动播放、后台服务与 3D 交互。

工作台外壳按用户提供的运营站截图调整：独立左侧品牌导航、右侧顶栏和通栏浅色工作区。桌面侧栏208px，中等容器168px，小屏隐藏侧栏并改为单列。2026-10-19访问运营站链接重定向飞书登录，当前布局依据此前用户截图，并非已核对登录后的实时页面。
