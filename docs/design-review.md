## 选中状态统一 · 2026-10-14

按用户要求将导航项、树节点、命令项、表格行、当前页码和日历日期的选中背景统一到 `--cs-selected-bg`，前景使用 `--cs-selected-fg`，悬停使用 `--cs-selected-hover-bg`。亮色背景混入当前品牌色 6%，暗色 12%；按后续用户反馈，选中后悬停保持相同背景，选中主文字保持原有字重，不额外加粗，这些比例是本次工程设计值。普通 hover 使用 `--cs-item-hover-bg`，不冒充持久选中。

线形 Tabs 继续以下划线表示选中；胶囊 Tabs 按后续用户反馈使用无描边的表面色滑块及轻阴影，与底槽拉开层次，选中文字仍使用统一前景色；复选框、单选和开关保留自身形状/勾选语义；状态徽标、错误、视频暗色控件与颜色色块仍保留各自必要的对比度和信息颜色。圆角及字重按组件职责保留，不通过全局属性选择器覆盖所有控件。

## 用户通道色板 · 2026-10-15

按用户提供的 64 通道色板图片中标注的 HEX 逐项录入 `--cs-chart-channel-01` 至 `--cs-chart-channel-64`。通道色固定，不随品牌/客户主题重新映射；绘图区保持白色，并配套固定轴文字与网格色。曲线、柱条、游标点与图例使用同一通道映射。

`ChartSeries.channel` 可显式指定 1–64，隐藏或重排序列不改变该通道色；未指定时按完整 series 顺序分配，显式 color 保留最高优先级。超过 64 个未指定通道的序列循环使用色板，不声称所有 64 色都具备两两可辨性或无障碍对比度认证。

## 导航图标语义

- 站内列表详情、查看全部和进入子页面：默认使用明确的文字链接；需要方向提示时使用统一图标库的 ChevronRight / ArrowRight。
- 右上箭头 / LinkExternal 仅用于外部站点或明确的新窗口跳转，不作为卡片、表格行尾、标题链接的默认装饰。
- 表格已有可点击名称时，不重复添加无标签的行尾箭头。确需独立详情操作时，提供“查看详情”文字或带 aria-label 的按钮。
- 使用 SVG 图标组件，禁止用 Unicode 箭头字符拼接按钮文案，避免不同平台基线、尺寸和字重不一致。

## 动效规范

采用用户提供的动效色阶：微交互 60ms、吸附 120ms、标准组件 200ms、Sheet 300ms、环境色 450ms。对应 `--cds-dur-fast/snap/base/sheet/slow`，原 cs duration 名称保持兼容。
减速曲线 `.165,.84,.44,1`；吸附曲线 `.32,.72,0,1`；超调曲线 `.34,1.3,.64,1` 作为可选强调效果，不默认应用于大面板。Tabs 指示器保留可中断弹簧，通过 snap 时长控制收敛尺度；非贝塞尔实现。逐字模糊继续使用每字90ms。减少动态效果时取消位移、旋转与过渡。

## 智能断行与移动端输入

标题使用 text-wrap:balance；正文使用 text-wrap:pretty。浏览器对 pretty 的支持与排版策略不同，不能承诺绝不出现孤字。长标识使用 overflow-wrap:anywhere 与 word-break:normal，保持英文单词完整，必要时允许应急断行。明确要求单行的按钮、数字和代码不强制参与正文换行。触屏手机输入文字至少16px，避免 iOS 输入聚焦自动缩放；不禁用用户手动缩放。

## 等宽数字与 SVG 图标层次

计数、测量读数、分页、时间和表格使用 font-variant-numeric:tabular-nums。消费项目的计时器和计数可复用 cs-tabular-nums 或 data-cs-numeric；字体须支持该 OpenType 特性。
图标继续使用现有 SVG 资产和原生 viewBox，不引入 Phosphor 或 Anthro 插件资产，也不重写为256坐标系。可选 cs-icon 次层以 data-layer="secondary" 标记，使用 currentColor 45% 混色；主层保持 currentColor，图标线宽仍为1.2px。SVG 不经过字体连字替换，辅助类同时明确 liga=0。
