# 文字样式复核 · 2026-10-14

本次复核针对字号、文字颜色与 CSS 继承一致性，不等同于完整视觉或 WCAG 审核。

## 修复

- 库内原生控件补充低优先级字体和颜色继承，避免依赖文档站的 CSS reset。颜色选择器渐变输入、文件选择按钮也使用所在控件的字体。
- 组件根节点和 Portal 浮层明确使用系统字体与语义字号；内部有意设置的标题、辅助文字、徽标及尺寸变体保留层级。
- 卡片标题、说明样式仅作用于卡片头部，不再改写嵌套组件的标题、段落或错误提示。
- Dialog 说明使用独立类，避免把失败/重试错误段落覆盖成辅助文字色；空状态标题和说明明确自己的文字层级。
- 指标单位使用独立类，避免通过通用 span 规则改写滚动数字。
- 文档侧栏的 aside/nav/link 规则限定到侧栏类，去除全局段落颜色规则，避免污染 InlineCTA、面包屑和预览组件。
- 表头默认沿用正文的字号和文字主色，当前排序列保留品牌色反馈。

## 浏览器复核

- 44 个公开组件路由，默认/Ocean 两套客户配置 × 明/暗模式，共 536 次可见原生控件字体检查；无浏览器默认 13.3333px 字号，无字体回退异常。
- 对输入框和 DataTable 表头另外比较其计算颜色与当前主题的正文色，均一致。
- Combobox、DropdownMenu、DatePicker、Dialog、Sheet、Popover 实际打开，检查四种主题组合，共 24 次浮层字体/颜色继承检查通过。
- 登录输入框 hover/focus 保持字号和尺寸；排序后保留排序语义及原字号。

维护时应同时检查独立使用、嵌套在 Card 中、Portal 打开后的实际计算样式。不要用宽泛的后代标签选择器代替具体的文字职责类。
