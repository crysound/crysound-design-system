# CarouselPagination 自动轮播与位置

`CarouselPagination` 是受控的当前位置导航。定时切换由共享 `Carousel` 管理，避免单独给分页点再创建一套计时器。

```tsx
<Carousel
  label="产品展示"
  items={slides}
  autoPlay
  interval={5000}
  arrows={false}
  showPlayControl={false}
/>
```

## 根据内容选择位置

| 内容 | 位置 | 条件 |
| --- | --- | --- |
| 大图、Banner、图片主体上方留白 | 图内底部居中 | 必须有安全区；距边缘16–24px；分页与背景对比清楚 |
| 图片底部含设备主体、标注或文字 | 内容下方 | 不覆盖关键图片信息 |
| 图文、文章、产品卡片、可交互内容 | 内容下方居中 | 与内容间隔16–24px，不覆盖 CTA、价格、说明 |
| 小嵌入容器、触屏、缩放后空间不足 | 优先移到内容下方 | 按容器宽度判断；本示例在所有容器宽度保持16:9，分页始终位于图片下方 |

组件不能判断任意 ReactNode 的图片构图和业务优先级，因此不根据文字数量猜测位置。消费应用根据上述内容规则，通过 `controlsClassName` / `paginationClassName` 与容器查询确定位置，始终定位在轮播自己的容器内。所有新间距是本示例的工程适配规则，不宣称任意官网原稿像素一致。

## 自动播放与可访问性

- 建议至少5秒一张；较长说明应延长阅读时间或关闭自动播放。默认不开启，消费页面明确设置 `autoPlay`。
- 默认保留暂停/继续控制（`showPlayControl=true`）。本示例按需求仅保留三张默认16:9图片和分页点，通过 `showPlayControl={false}` 隐藏按钮；悬停暂缓，键盘焦点进入后停止，之后通过分页点手动浏览。
- 页面隐藏期间暂缓，减少动态效果时禁用自动播放。自动切换不抢焦点；自动播放期间不把每张内容作为实时通知反复朗读。
- 点击圆点或使用方向键、Home/End 手动切换；用户聚焦分页后不会被自动翻页打断。
- 0条显示空状态；1条不显示分页，不开定时器。建议2–7个分页点，更多内容由业务调整分组或选择更合适的页码导航。
- 分页不替代 DataTable / Pagination 的记录分页。不要把一个分页条放在整个页面底部控制不相邻的多个区域。

## 连续切换与图片准备

轮播保留以稳定id标识的各页内容，使用同一条300ms轨道平移，不再销毁当前页后从透明淡入。轨道按内容共同撑高，避免分页和容器随切换上下跳动；建议图文轮播使用相同图片比例和相近内容长度。

切换前等待目标页图片加载并完成decode（不支持decode时等待load）；等待期间保留原画面。快速再次选择只提交最新目标，旧的异步结果不会覆盖它；图片加载或decode失败不会锁死切换，失败展示由内容组件负责。示例默认图片使用内联SVG，不依赖网络图片。非当前页使用aria-hidden和inert，避免重复播报和隐藏链接进入Tab顺序。减少动态效果时关闭轨道过渡，自动播放、悬停暂缓及聚焦停止规则保留。

实现参考[Open Claude UI的MediaLightboxViewer](https://github.com/Caho1/open-claude-ui/blob/main/code-examples/MediaLightboxViewer.tsx)中保留画廊轨道与提前加载相邻图片的思路，未引入额外依赖。

默认图片示例的建议间距：图片到分页点击区域为8px，桌面端到可见圆点为20px（32px点击区域内含12px留白）；触屏保留44px点击区域。该间距仅应用于此紧凑示例。

默认图片仅用于演示轮播与分页；不包含营销文案或加载骨架。实际业务图片由消费页面替换，继续保持16:9比例与固定分页位置。
