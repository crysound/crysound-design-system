# 常用图表组合

通用图表与声学测量图表在同一组件页分组展示。通用图表使用现有图表色板的前六个色相（紫、橙、绿、紫、黄、青），以68%原色与32%白色形成柔和中间色阶（视觉提案）、居中标题、浅色点线网格和底部图例；适用于中小数据集。新增 API 从 packages/ui 导出，未引入商业图表依赖。

| 图表 | 使用场景 | 约束 |
| --- | --- | --- |
| LineChart | 周期趋势 | 缺失值断线 |
| BarChart | 分类数量对比 | 数量轴应包含零 |
| StackedBarChart | 总量及构成 | 正负值分别累计；同单位，不混合量纲 |
| AreaChart | 规模随周期变化 | 非堆叠透明填充，不能用填充面积读分类占比 |
| ScatterChart | 两个连续变量关系 | 配置 xScale="linear"；数据按 x 递增；不连线，不表达因果 |
| DonutChart | 少量互斥分类构成 | 仅有限正值参与环形；零、负数及无效值不生成扇区，原数据保留于表格 |

前三个新增直角坐标组件沿用 ChartProps。图例按钮支持键盘切换，数据点可通过 Tab、左右方向键读取，Esc 隐藏读数。DonutChart 的 data 为 {label, value, color?}[]，label 应唯一，图例焦点显示分类值，点击隐藏后重新计算可见合计；表格占比始终以全部有效数据计算。各图保留数据表、空数据和加载状态。

实现对照用户指定的 AG Charts 类型清单（https://www.ag-grid.com/charts/），仅吸收图表选择与视觉组织；不声称具有该库全部功能、许可或性能。未实现百分比堆叠、双轴组合、缩放和大数据虚拟化。
