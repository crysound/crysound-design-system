# 业务表格组合

组件页提供声像云端、设备与算力、通用事项、监测点设备、噪声事件、测量记录六个本地合成示例。沿用14px正文、浅色表头、单向横分隔线、状态文字与同行同字号、数值右对齐及等宽数字。名称与编号合并首列，无效读数显示“—”。不以状态给普通行整行染色，选中行保留勾选和浅底。

## 共享组件能力

DataTable 保留搜索、分页和跨页选择，新增列值筛选、三态排序（升/降/无）、列显隐、固定表头、固定首个可见数据列、最大高度滚动、CSV 导出、加载/错误/重试。DataColumn 使用 accessor 原始值进行排序筛选与导出，cell 仅负责显示。accessor 可返回 null，表格显示缺失，升降序排序均置后。width 是列最小宽度；pinned 仅对首个可见数据列生效。列显隐至少保留一列。

搜索覆盖全部列，与各列精确匹配筛选取交集。搜索、筛选、排序回到第一页。跨页选择不因筛选消失，当前页全选只影响当前页；数据源删除记录时自动清理选择。重置视图恢复搜索、筛选、排序、列和分页，不清空选择；清除选择是独立操作。

CSV 输出当前筛选排序后的全部记录，不限当前页；输出可见列，列 exportable=false 可排除操作列。字符串前缀防公式执行，数字负数保持数值。用户点击导出后才下载，无外部传输。

loading 和 error 替换旧数据视图，禁用搜索/筛选/导出；error 的 onRetry 由消费项目实现。固定列与表头保持主题背景，选择列固定宽44px；小屏只固定勾选列，数据首列随表格自然横向滚动，避免占满可视区；控件保持44px触摸高度。保留原生 table、caption、列标题、复选框及 aria-sort；查看详情使用既有 Radix Dialog。

## 边界

对照用户指定的 https://www.ag-grid.com/ 梳理常见表格能力；未引入 AG Grid 或商业组件。仍适用于中小型客户端数据，未实现服务端分页、虚拟滚动、单元格编辑、拖动列宽、行分组或透视统计。业务数据获取、声级计算、权限与批量操作由消费项目提供。

## 场景字段与组件组合

- 声像云端：任务编号、项目、检测类型、上传/分析状态、处理进度、文件数、数据量与更新时间。失败显示中断原因；等待上传不显示虚假的运行进度。详情可查看采集设备。
- 设备与算力：资源组、节点类型、连接状态、CPU 核数、负载、存储与当前任务。负载超过100%保留原始读数，进度轨道封顶并解释超过基准；离线读数为缺失。
- 通用事项：部门、负责人、优先级、状态、截止日期与预算。预算显示千分位但排序和 CSV 保持数值。
- 声学领域：监测设备、噪声事件、测量记录。事件类型与区域独立组合，避免每个区域只剩单一事件类型。

筛选复用 Select，列显隐复用 Popover + Checkbox，进度复用 Progress，详情复用 Dialog；按钮、Tabs、分页同样使用共享组件。场景字段、示例数据与解释留在文档应用，未加入共享组件。对照 AG Grid example 的场景切换与列配置思路，不复制商用功能或真实账号数据。

## 列对齐规则

文本、名称、状态、日期默认左对齐；数值列显式设置align=right，表头标题与单元格共用右侧基线。所有列均采用标题文字在前、排序图标在后；数值列的标题与图标作为整体右对齐。操作列采用align=center，标题与按钮文字中心一致。表头排序按钮撑满内容宽度，不以按钮自身宽度推断对齐。进度与负载保留数值右对齐，单位放在表头。依据AG Grid的numericColumn/rightAligned规则统一数值表头和内容；操作列居中是本系统的组合约定。

## 搜索与筛选的显示规则

以下为本项目默认设计阈值，可由业务显式覆盖，并非行业通用标准：
- 原始数据少于 10 条：隐藏搜索和列筛选，优先直接浏览。
- 10–19 条：仅显示搜索。
- 20 条及以上：显示搜索；仅显示声明 `filterable` 且至少有两个非空不同值的筛选字段。
- 按完整输入数据计算，不按当前页或筛选后的结果数计算。已有搜索、筛选条件在数据量下降时仍显示，直到用户清除，避免无法撤销条件。
- `searchMode`、`filterMode` 支持 `auto`（默认）、`always`、`never`。少量但需反复定位的工作流可显式开启；单一值字段不生成无效筛选。
- 远程分页由消费应用依据服务端总量选择模式，不使用当前页条数推断整体规模。筛选字段仍由业务依据定位需求声明，避免为所有列自动生成筛选。
