# 业务表格组合

组件页提供监测点设备、噪声事件、测量记录三个本地合成示例。沿用14px正文、浅色表头、单向横分隔线、状态文字与同行同字号、数值右对齐及等宽数字。名称与编号合并首列，无效读数显示“—”。不以状态给普通行整行染色，选中行保留勾选和浅底。

## 共享组件能力

DataTable 保留搜索、分页和跨页选择，新增列值筛选、三态排序（升/降/无）、列显隐、固定表头、固定首个可见数据列、最大高度滚动、CSV 导出、加载/错误/重试。DataColumn 使用 accessor 原始值进行排序筛选与导出，cell 仅负责显示。accessor 可返回 null，表格显示缺失，升降序排序均置后。width 是列最小宽度；pinned 仅对首个可见数据列生效。列显隐至少保留一列。

搜索覆盖全部列，与各列精确匹配筛选取交集。搜索、筛选、排序回到第一页。跨页选择不因筛选消失，当前页全选只影响当前页；数据源删除记录时自动清理选择。重置视图恢复搜索、筛选、排序、列和分页，不清空选择；清除选择是独立操作。

CSV 输出当前筛选排序后的全部记录，不限当前页；输出可见列，列 exportable=false 可排除操作列。字符串前缀防公式执行，数字负数保持数值。用户点击导出后才下载，无外部传输。

loading 和 error 替换旧数据视图，禁用搜索/筛选/导出；error 的 onRetry 由消费项目实现。固定列与表头保持主题背景，选择列固定宽44px；小屏只固定勾选列，数据首列随表格自然横向滚动，避免占满可视区；控件保持44px触摸高度。保留原生 table、caption、列标题、复选框及 aria-sort；查看详情使用既有 Radix Dialog。

## 边界

对照用户指定的 https://www.ag-grid.com/ 梳理常见表格能力；未引入 AG Grid 或商业组件。仍适用于中小型客户端数据，未实现服务端分页、虚拟滚动、单元格编辑、拖动列宽、行分组或透视统计。业务数据获取、声级计算、权限与批量操作由消费项目提供。
